
# Actuator Node - Fire Alarm System

ESP32 actuator node for an IoT fire alarm system.

## Components
- ESP32 DevKit V1
- Relay Module
- 2 Servo Motors
- Buzzer
- 3 LEDs
- Push Buttons
- Slide Switch

## Functions
- Receive fire alarm commands
- Activate sprinkler relay
- Open exit door and window
- Activate buzzer and warning LEDs
- Simulate power failure
- Reset alarm system

## Simulation
Platform: Wokwi
Language: Arduino C++
Library: ESP32Servo

## Commands
- ALARM
- RESET
- STATUS
